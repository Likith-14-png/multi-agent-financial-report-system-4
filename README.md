# Project Objective

The Multi-Agent Financial Research System is an AI-powered platform that assists finance students, MBA candidates, and early-career analysts in understanding complex financial documents.

The system automates financial document analysis using multiple specialized AI agents that collaborate to:

- Upload and process company financial reports.
- Extract important financial metrics and ratios.
- Detect financial risks and anomalies.
- Compare multiple companies.
- Answer financial research questions with source citations.
- Generate analyst-style financial research reports in PDF format.

---

# Features

- Upload one or multiple company annual reports
- Automatic document parsing and chunking
- Vector database indexing using ChromaDB
- Financial metric extraction
- Financial red flag detection
- Multi-company comparison
- Question-answering with source citations
- AI-generated financial research reports
- Multi-agent collaboration

# Workflow

1. User uploads one or more financial reports.
2. Document Agent processes and indexes documents.
3. Extraction Agent extracts financial metrics.
4. Red Flag Agent identifies potential risks.
5. Comparison Agent compares companies.
6. Research Agent answers user questions with citations.
7. Report Agent generates a comprehensive PDF report.

---

# Expected Outcome

The system enables users to analyze lengthy financial reports quickly by providing accurate financial insights, risk detection, company comparisons, and AI-generated research reports with source-grounded answers.
